## 3. サードパーティコンポーネントのライセンス分類

Matcap Maker に組み込まれているすべてのオープンソースコンポーネント（npm パッケージ、Rust クレート、GLSL シェーダー）は、**商用利用および有償バイナリ配布が完全に可能なライセンス** のみで構成されています。

### ① パーミッシブ（寛容型）ライセンス（大多数）
- **MIT License**（Svelte, Vite, fflate, immer, 各種 Rust クレート）
- **Apache-2.0** / **Apache-2.0 OR MIT**（Tauri 2, 各種 Rust クレート）
- **BSD-3-Clause**（`exr`, `alloc-no-stdlib` 等）
- **Zlib License**（圧縮関連クレート）
- **Unlicense / 0BSD / CC0**（パブリックドメイン同等）

**遵守義務**: ソフトウェアの再配布物（バイナリ配布を含む）において、元の著作権表示およびライセンス条文を添付すること。

### ② ファイル単位の弱コピーレフトライセンス
- **MPL-2.0**（Mozilla Public License 2.0: `cssparser`, `selectors` 等のパーサーライブラリ）
  - **特徴**: 当該ライブラリのソースコードファイル自体を直接改変して再配布する場合にのみ改変ファイルのソース開示義務が生じます。改変せずそのままライブラリとしてリンク・利用する形態（本ツールの構成）では、プロジェクト全体のコードを開示する義務は一切発生しません。

### ③ 感染性コピーレフト（GPL / AGPL）の完全不在
- プロジェクト全体にソース開示を強制したり、商用利用・有償配布を制限する **GPL / AGPL ライセンスのコンポーネントは一切含まれていません**。

## 4. 公開・配布形態別のチェックリスト（実務遵守要件）

### A. GitHub リポジトリ公開時
- [x] リポジトリ直下に [`LICENSE`](../LICENSE) が配置されていること（本フォルダの `LICENSE.txt` と同期）。
- [x] `LICENCE/` フォルダ配下にサードパーティライセンス一覧（`THIRD_PARTY_LICENSES.md` / `THIRD_PARTY_LICENSES.txt`）が配置されていること。

### B. デスクトップ版バイナリ（exe / インストーラ）配布時（BOOTH / Steam / GitHub Releases 等）
- [x] **アプリ内表示**: アプリのメニューバー「ヘルプ」→「バージョン情報 / ライセンス」から、全サードパーティの著作権およびライセンス全文がスクロール閲覧・検索可能であること（自動組み込み済み）。
- [x] **同梱配布（推奨）**: ポータブル版の配布 zip ファイルまたはインストーラに、本フォルダの `LICENSE.txt` および `THIRD_PARTY_LICENSES.txt` を同梱すること。

### C. Web版（単一HTML版）公開時（GitHub Pages / 任意Webサーバ）
- [x] **単一HTMLファイル内の完結**: Web版 HTML のビルド時に、必要なライセンス情報（npm パッケージおよび GLSL 著作権表示）がインラインバンドルされ、ヘルプダイアログからいつでも閲覧可能です。これにより、HTML 1 ファイル単体でライセンス表記要件を自動的に満たします。

## 5. ライセンス表記の自動更新手順

依存パッケージの追加やバージョンアップを行った際は、以下のコマンドを実行することでライセンス情報が最新の状態へ自動更新されます。

```powershell
# 1. 依存関係のライセンスを収集して src/generated/licenses.json を更新
pnpm licenses

# 2. LICENCE/ 配下のテキスト・Markdown ドキュメントを自動再生成
node scripts/gen-license-files.mjs
```

または、通常のリリースビルドコマンド（`pnpm build`）実行時にも `src/generated/licenses.json` は自動同期されます。
