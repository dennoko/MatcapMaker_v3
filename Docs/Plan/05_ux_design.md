# 05. UI/UX 設計

## 1. 方針
- **見ながら、触って決める**：数値入力は補助にとどめ、プレビュー上での直接操作を主役にする。
- **迷わない既定値**：レイヤーを追加した瞬間に「それらしい」見た目になるよう既定値とプリセットを用意する。
- **何をしても戻せる**：Undo/Redo、自動保存、ダブルクリックで既定値に戻す。
- **速さを感じさせる**：操作から 1 フレーム以内に反映し、重い処理は段階的に仕上げる。

- パネル幅は調整でき、折りたたみも可能。ウィンドウが縦長になったら、Inspector をプレビューの下に回すレスポンシブ配置にする（現行 ROADMAP の「縦並び」を反映）。
- レイヤーパネルは **上が前面**。各行にサムネイル、表示の切り替え、不透明度のミニバー、ブレンドモードの略称を表示する。

## 3. 直接操作（ギズモ）

| 対象 | 操作 |
|---|---|
| Spot Light の方向 | 球上のハンドルをドラッグ。**ハイライトそのものを掴んで動かす**感覚にする |
| Spot Light の形状 | ハンドル周りのリングで回転、端のハンドルで scale X/Y、ホイールで range |
| Gradient | プレビュー上に始点と終点の矢印を表示し、ドラッグで角度を決める。Radial は中心と半径 |
| Image | 平面表示でバウンディングボックスを動かす、拡大縮小する、回転する |
| Fresnel | 輪郭付近をドラッグすると power と bias が変わる（Inspector と連動） |
| スポイト | 任意のカラーフィールドで `I` を押すかアイコンを押し、プレビューから色を拾う |

ギズモは選択中のレイヤーのものだけを表示し、`G` で表示/非表示を切り替えられる。

## 4. Inspector の入力部品
- **ScrubNumber**：ラベルを横にドラッグして値を変える（Shift で細かく、Ctrl で粗く）。クリックすると数値入力、ホイールでも変更できる。
- **ダブルクリックで既定値にリセット**、右クリックメニューで「既定値に戻す / 値をコピー / 貼り付け」。
- スライダーは `softMax`（よく使う範囲）で表示し、数値入力なら `max` まで入れられる。
- ColorPicker：HSV のホイールと数値入力（HEX / RGB / HSV）、最近使った色、スポイト。
- GradientEditor：現行の操作（クリックでストップを追加、ドラッグで移動、ダブルクリックで色を変える、削除）を引き継ぎ、さらに以下を追加する：
  - 補間の方法（RGB / OKLab）
  - 反転
  - ストップ位置の均等配置
- ブレンドモードのドロップダウンは、**項目にカーソルを合わせるだけで仮適用してプレビュー**する（確定するまで履歴には残さない）。

## 5. レイヤー操作
- 追加：`＋` ボタンまたは `Tab` でコマンドパレットを開き、名前で検索して選択中レイヤーの上に挿入する。
- **Alt+クリックで表示を切り替えるとソロ表示**。Ctrl+クリックで複数選択し、まとめて表示の切り替え、削除、複製ができる。
- ドラッグ＆ドロップ：
  - 画像ファイルをプレビューにドロップすると Image レイヤーを作る
  - 画像をノーマルマップ枠にドロップするとノーマルマップとして設定する
  - `.mcproj` / 旧 `.json` をドロップすると開く
  - `Ctrl+V` でクリップボードの画像を Image レイヤーとして貼り付ける
- 将来：グループ、マスク（レイヤーのサムネイルの横にマスクのサムネイルを並べる）

## 6. プリセット
- **プロジェクトプリセット**（金属、プラスチック、肌、トゥーン、ガラスなど）はサムネイル付きのギャラリーから始められる。新規作成の画面にもなる。
- **レイヤープリセット**は、レイヤーの右クリックメニューから「プリセットとして保存」で登録する。ユーザーのプリセットは `Documents/MatcapMaker/presets/` に保存する。

## 7. エクスポート
- `Ctrl+E`：前回と同じ設定で即座に書き出す（初回はダイアログを開く）。
- `Ctrl+Shift+E`：ダイアログを開く。解像度、パディング、形式、背景を設定でき、**パディングの効果を拡大プレビューで確認**できる。ファイル名のテンプレート（`{project}_{size}.png`）も指定できる。
- 書き出しが終わったらトーストで知らせ、「フォルダを開く」操作を添える。

## 8. ショートカット（主要なもの）

| キー | 操作 |
|---|---|
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直す |
| Ctrl+N / O / S / Shift+S | 新規 / 開く / 保存 / 名前を付けて保存 |
| Ctrl+E / Ctrl+Shift+E | クイックエクスポート / エクスポートダイアログ |
| Tab | レイヤー追加のコマンドパレット |
| Ctrl+D / Delete | 複製 / 削除 |
| Ctrl+↑ / ↓ | レイヤーを前面 / 背面へ移動 |
| H | 選択レイヤーの表示を切り替え |
| 1 / 2 / 3 / 4 | Sphere / Flat / NormalMap / Split 表示 |
| G | ギズモの表示を切り替え |
| \ | 選択レイヤーの Before/After 比較 |
| F1 | ショートカット一覧 |

## 9. その他
- **言語はその場で切り替える**（再起動しない）。OS の言語から初期値を決める。
- テーマは Dark（既定）と Light。
- ステータスバーに解像度と描画時間を表示する（デバッグ表示は隠し設定）。
- 初回起動時は、3 ステップの簡単なツアー（レイヤーを追加 → ギズモで調整 → 書き出し）を案内し、スキップもできる。
- アクセシビリティ：キーボードだけで一通り操作でき、フォーカスリングを表示し、UI の拡大縮小（Ctrl+ +/-）に対応する。
